# Fraud Detection using Machine Learning

## Project Overview

This project detects whether a financial transaction is fraudulent or not using Machine Learning.

## Dataset

The dataset contains transaction details such as:

- Transaction type
- Transaction amount
- Origin account balance
- Destination account balance
- Fraud status

## Workflow

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Correlation Analysis
7. Data Preprocessing
8. Feature and Target Separation
9. Train-Test Split
10. Feature Scaling
11. Logistic Regression
12. Prediction
13. Model Evaluation
14. Confusion Matrix
15. Classification Report
16. ROC Curve and AUC
17. User Input Prediction

## Algorithm

Logistic Regression

## Target

`isFraud`

- 0 → Not Fraud
- 1 → Fraud
